# OUxSBLI プロジェクトの背景

## 1. はじめにおよび概要

**OUxSBLI**は、**O**kayama **U**niversity × **SBLI**（衝撃波-境界層相互作用）の略称です。これは、最新のGPUコンピューティングと高次有限差分法を用いて、圧縮性流れ、特に衝撃波-境界層相互作用を研究するために設計された、GPU加速型計算流体力学（CFD）ソルバーです。

本プロジェクトは、岡山大学の学生による、複雑な空力現象や極超音速現象を研究するための最先端ツールを開発する取り組みです。

---

## 2. 科学的背景

### 2.1 支配方程式

OUxSBLIは、**3次元圧縮性ナビエ・ストークス方程式**（または非粘性モードのオイラー方程式）を解きます：

$$\frac{\partial \rho}{\partial t} + \nabla \cdot (\rho \mathbf{u}) = 0$$

$$\frac{\partial \rho \mathbf{u}}{\partial t} + \nabla \cdot (\rho \mathbf{u} \otimes \mathbf{u}) + \nabla p = \nabla \cdot \boldsymbol{\tau}$$

$$\frac{\partial E}{\partial t} + \nabla \cdot (E \mathbf{u} + p \mathbf{u}) = \nabla \cdot (\boldsymbol{\tau} \cdot \mathbf{u}) + \nabla \cdot \mathbf{q}$$

ここで：
- $\rho$: 流体密度
- $\mathbf{u}$: 速度ベクトル
- $p$: 圧力
- $E$: 単位体積あたりの総エネルギー
- $\boldsymbol{\tau}$: 粘性応力テンソル
- $\mathbf{q}$: 熱流束ベクトル

### 2.2 研究の焦点：衝撃波と境界層の相互作用

**SBLI**は、衝撃波が境界層に衝突し、複雑な三次元分離流領域を形成する際に発生する。この現象は、以下の分野において極めて重要である：

- **極超音速空力学**：航空機の胴体および翼における衝撃波誘発の剥離
- **ロケットエンジン**：超音速ノズル内の衝撃波構造
- **超音速吸気口**：流れの制御および始動問題
- **ラムジェット／スクラムジェット推進**：吸気口内の超音速流れ

**課題**：
- 非定常な衝撃波の運動
- 乱流の発生と増幅
- マルチスケール相互作用（衝撃波の曲率 ↔ 境界層の厚さ）
- 正確な予測には、衝撃波捕捉スキームを用いたDNSまたはLESが必要

## 3. 計算アプローチ

### 3.1 なぜGPUアクセラレーションなのか？

**問題の規模**：
- 実用的なSBLIシミュレーション：2,000万～2億の格子点
- 数百～数千の時間ステップ
- 収束解析のための複数のスキーム／精度

**従来のCPU性能**：
- 単一のIntel Xeon：約200～500 GFLOPS
- 完全なSBLIシミュレーション：数週間～数ヶ月

**GPU加速**：
- 単体のRTX 4090：約1000 TFLOPS以上（40倍の高速化）
- SBLIシミュレーション：数時間～数日
- アルゴリズム開発のための迅速な反復計算が可能

### 3.2 高次法を採用する理由

**なぜ2次法ではないのか？**
- 2次法では精度を確保するために非常に細かい格子が必要
- 滑らかな流れ：KEEP/SLAU(4次)は2次法に比べて5倍粗い格子を使用可能
- DNS/LES：乱流スペクトルには高精度が必要

**効率のトレードオフ**：
- 広いステンシル（より多くのメモリ帯域幅）
- 大きな時間ステップ（高精度 → より大きなCFL）
- 結果：同等の精度で2次法に比べて2～4倍の高速化

### 3.3 スキーム選択の指針

| スキーム | 目的 | 精度 | コスト | 最適用途 |
|--------|---------|----------|------|----------|
| **KEEP** | 運動エネルギー保存 | 2次/4次/6次 | 低 | 滑らかな乱流、DNS |
| **SLAU** | 低散逸、衝撃波適応型 | 2次/4次/6次 | 中 | SBLI、滑らか＋衝撃波の混合 |
| **Roe** | 古典的、堅牢 | 2次 | 低 | 極超音速、極端な衝撃波 |
| **Hybrid** | 適応的切り替え | 可変 | 可変 | 汎用 |

## 4. 適用事例

### 4.1 基礎研究

#### テイラー・グリーン渦 (TGV)
```
目的：コードの検証、収束速度の確認
設定：周期領域、滑らかな初期渦
ケース：
  - ETGV：オイラー型TGV（圧縮性、非粘性）
  - NSTGV：ナビエ・ストークス型TGV（粘性あり、LES）
出力：運動エネルギー減衰曲線、スペクトル解析
```

**なぜTGVか？**
- 解析解が存在する（衝撃波形成前）
- 移流、粘性、LESモデルの純粋な検証が可能
- 数値スキームに依存しない（すべて同じ減衰率を示すはず）
- 格子解像度および精度オーダーに対する感度が高い

#### 等エントロピー渦（IVST）
```
目的：対流スキームの検証
設定：一様な圧縮性流れ中の対流渦
目標：多くの波長にわたって数値誤差が小さいこと
```

#### ケルビン・ヘルムホルツ不安定（KHI）
```
目的：乱流遷移、混合層の物理現象の検証
設定：2つの逆流する流れ、せん断によるロール
特徴：渦の巻き上がり、ペアリング、小規模構造の生成
```

### 4.2 応用研究

#### 乱流境界層 (TBL)
```
目的：壁面境界層乱流の研究
設定：チャネルまたは平板構成
条件：マッハ数2～5、Reτ ≈ 200～1000
出力：平均プロファイル、レイノルズ応力、スペクトル、構造
```

#### 衝撃波・境界層相互作用 (SBLI)
```
目的：主な焦点 - SBLIの物理現象の理解
実験構成：乱流境界層に衝突する斜め衝撃波
条件：衝撃波による剥離領域
物理現象：非定常な衝撃波の運動、渦度生成、境界層の不安定化
出力：
  - 平均流のトポロジー（剥離バブル）
  - 圧力による変動
  - 超音速コヒーレント
  - 衝撃波の運動統計
```

## 5. 技術的機能

### 5.1 離散化手法

**空間（対流）**:
- KEEP法：運動エネルギーおよびエントロピー保存（人工的な散逸なし）
- SLAU法：低散逸AUSM（衝撃波適応型補間）
- Roe法：衝撃波に対する古典的なフラックス分割法
- 精度：2次、4次、6次有限差分

**空間（粘性）**：
- 2次: Gaitonde-Visbal 形式
- 4次: ME4-Base（高精度、ステンシルサイズが大きい）
- LES: サブグリッド散逸のための選択的混合スケールモデル

**時間**:
- 3次 TVD ルンゲ・クッタ法（KEEP/SLAU との安定性確保用）
- 4次古典的RK4（高精度、より小さなCFLが必要）
- SBLIのための参照状態再スケーリングを伴う変種

### 5.2 並列計算

**GPUサポート**:
- NVIDIA HPC SDK（nvfortranコンパイラ）
- CUDA Fortran GPUカーネル
- ステンシル演算のための共有メモリ最適化
- 結合されたグローバルメモリアクセスパターン

### 5.3 テストケース

| ケース | 方程式 | 格子サイズ | 領域 | 入力ファイル |
|------|-----------|-----------|--------|-------------|
| ETGV | オイラー | 513³ | $[0,2\pi]^3$ | 3D_solver/ETGV/ |
| NSTGV | NS | 513³ | $[0,2\pi]^3$ | 3D_solver/NSTGV/ |
| IVST | オイラー | 256³ | $[0,25]×[0,25]×[0,50]$ | 3D_solver/IVST/ |
| KHI | NS | 256³ | 領域固有 | 3D_solver/KHI/ |
| TBL | NS | 256×512×128 | チャネル形状 | 3D_solver/TBL/ |
| SBLI | NS (デュアル領域) | 512×350×256 | BL + 衝撃波 | 3D_solver/SBLI/ |
